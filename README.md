# Encriptador de texto

Desafío del programa **Alura Latam + Oracle Next Education (ONE)**. Lo hice para demostrar lo aprendido en el curso
de lógica de programación y HTML, CSS y JavaScript.

## Qué hace

Encripta y desencripta un texto cambiando cada vocal por una palabra clave:

| Vocal | Se cambia por |
|---|---|
| e | enter |
| i | imes |
| a | ai |
| o | ober |
| u | ufat |

Por ejemplo, `gato` queda como `gaitober`, y al desencriptarlo vuelve a `gato`.

- Solo acepta letras minúsculas y sin acentos; si el texto tiene mayúsculas o acentos, me avisa y limpia el campo.
- Muestra el resultado en pantalla.

## Cómo lo uso

No necesita instalar nada: abro `index.html` en el navegador.

## Tecnologías

HTML, CSS y JavaScript puro.
